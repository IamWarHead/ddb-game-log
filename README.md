# D&D Beyond Gamelog

Bridge your D&D Beyond rolls and characters to Foundry VTT. **No browser extension required.**

Rolls made on dndbeyond.com or in the D&D Beyond player app show up as chat cards in your Foundry world, for everyone at the table. Version 3 adds live character updates, statistics, Discord, and more.

**Documentation:** https://iamwarhead.github.io/ddb-game-log/

## Install

In Foundry, open **Add-on Modules → Install Module** and search for **D&D Beyond Gamelog**, or paste this manifest URL:

```text
https://github.com/IamWarHead/ddb-game-log/releases/latest/download/module.json
```

Requires Foundry VTT v13 or newer (v14 verified) and dnd5e 5.0.0 or newer. Coming from version 2? Uninstall it first, see [Coming from version 2](https://iamwarhead.github.io/ddb-game-log/install.html#coming-from-version-2). Then follow the [first steps](https://iamwarhead.github.io/ddb-game-log/first-steps.html).

## Features

- **Rolls in chat:** real dnd5e rolls with kept and dropped dice, roll breakdown, targets with hit and miss, and roll privacy. Free.
- **Character linking:** by hand, or automatic for ddb-importer characters.
- **Card look:** themes, player colours, avatars, item and spell links.
- **Character sync (PRO):** hit points, armor class, conditions, resistances and more follow D&D Beyond live; apply damage and healing from the card.
- **Monster rolls and the D&D Beyond player app (PRO).**
- **Avrae rolls (PRO, experimental):** rolls made with the Avrae Discord bot, off by default.
- **Automatisms (PRO, experimental):** spell templates, effects and usage buttons on cards.
- **Combat tracker (PRO, experimental):** the D&D Beyond encounter in Foundry's tracker.
- **Statistics:** party overview, highlights, luck, awards, charts, session history, import from D&D Beyond, export and a player view.
- **Discord (PRO):** public rolls and a session recap in your channel.
- **Integrations:** Midi-QoL (experimental), Dice So Nice, JB2A and Automated Animations.

Every feature page states the tier it needs, see [Features](https://iamwarhead.github.io/ddb-game-log/features/) and [Tiers](https://iamwarhead.github.io/ddb-game-log/tiers.html).
