# DDB Gamelog

DDB Gamelog (module id `ddb-game-log`) brings your D&D Beyond game log into Foundry VTT. Rolls made on D&D Beyond show up as chat cards in your Foundry world, with no browser extension.

This site documents **version 3**. You are a Foundry GM or a player in a GM's world; you do not need to know anything about code.

| | |
| --- | --- |
| Foundry VTT | v13 minimum, v14 verified |
| Game system | dnd5e 5.0.0 or newer |
| Module id | `ddb-game-log` |

{: .note }
**Coming from version 2?** Version 3 replaces v2 and installs over the same module id. Uninstall v2 first, then install v3; your settings and character links are read once on the first start. See [Coming from version 2]({{ '/install.html' | relative_url }}#coming-from-version-2).

## Get started

1. Make sure you meet the [requirements]({{ '/install.html' | relative_url }}#requirements).
2. [Install the module]({{ '/install.html' | relative_url }}) in Foundry.
3. Follow [First steps]({{ '/first-steps.html' | relative_url }}) to connect your world.
4. Roll something on D&D Beyond and look at your Foundry chat.
